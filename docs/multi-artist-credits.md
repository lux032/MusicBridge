# 多艺术家署名适配与验收

## 行为

继续使用服务端返回的 `artists: [{id,name}]`，不在客户端按逗号拆分或修改归属。

- 单人点击直接进入艺人页，多人点击显示原有选择器。
- 服务端修正旧曲目后，执行一次完整曲库刷新。
- 刷新替换旧艺人引用和关联；队列只更新艺人元数据，不改播放 URL、离线文件、队列位置、推荐上下文或播放会话。
- 下载记录升级到数据库 v19，保存 `artist_refs`；旧下载在联网刷新后补上引用，不重新下载音频。
- 收藏、歌单缓存、下载记录内的署名同步更新。离线时使用最后一次已知数据。

## 验收

1. 先升级服务端并完整扫描，确认合作曲目的 `artists` 已有两位或更多独立 ID。
2. 安装新版 Android，执行完整曲库刷新，点播放页艺人文字可选择每一位。
3. 两位艺人页都能找到合作歌曲；真实组合名不会被客户端自行拆开。
4. 下载歌曲，退出重开并断网，检查选择器仍保留多人引用。
5. 在服务端修正一首已下载歌曲，联网刷新后检查下载页与队列署名更新，音频路径、下载大小和曲目收藏不变。
6. 播放中刷新不应中断、切歌或多记一次播放。
